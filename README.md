# Moments
This, not that —\
and the line is a meeting.\
What changes carries what it changed from.\
Not a fifth thing.\
A mind, turned.

---

## What this is

Some experiences resist description. Not because they are too complicated, but because
ordinary words are the wrong size for them. *Grief* does not describe grief for a particular
person. What describes it is smaller and more exact: what was lost, how it was held, how fast it
went, and how much it mattered.

Those four questions are the whole of this notation.

It began as a way to write poems. Specify a state in four marks, then go find the one image that
is true to it. It turned out to be a usable way of reading moments as well — and, with care, a
way of saying what persists underneath them.

The notation produces poems that feel recognizably true to the states they came from. Whether that tells us anything deeper about
meaning is left open on purpose.

**A lens, not a law.** Everything below is held at that strength.
